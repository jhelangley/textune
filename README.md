# textune

A musical toy built with React and Tone.js that converts text input into note sequences.

Try the application here: https://textune.onrender.com/

Notes are chosen based on position of letter in the alphabet, with duration between notes chosen based on how common the letter is. 

Having originally learned React around six years ago via the FreeCodeCamp syllabus, a lot has changed since then. I built this app to refresh my memory of React and get to grips with the current conventions (useEffect over componentDidMount, etc).
